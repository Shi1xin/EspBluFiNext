# Branding and compatibility wording

EspBluFiNext is an independent project. The app communicates with devices
that implement Espressif's BluFi protocol and uses the ESP32 and BluFi names
to describe compatibility.

## Approved wording

Use this statement in the README, About screen, release page, and product
description:

> EspBluFiNext is an independent iOS diagnostic client for Espressif
> BluFi-compatible ESP32 devices. It is not affiliated with, sponsored by, or
> endorsed by Espressif Systems (Shanghai) Co., Ltd. “ESP32” and “BluFi” are
> used only to describe compatibility.

Chinese:

> EspBluFiNext 是面向 Espressif BluFi 兼容 ESP32 设备的独立 iOS 调试客户
> 端，与 Espressif Systems (Shanghai) Co., Ltd. 无隶属、赞助或背书关系。
> “ESP32”和“BluFi”仅用于描述兼容性。

Compatibility descriptions such as “for ESP BluFi-compatible devices” and
“tested with ESP32-S3” are appropriate. Keep “official”, “endorsed”, and
similar claims out of the app name, icon, screenshots, release title, and
marketing copy.

## Logos and visual assets

- Use an original app icon and original interface artwork.
- Do not use or trace Espressif's logo, wordmark, official app icon, or
  promotional screenshots.
- Do not place an Espressif logo beside the EspBluFiNext name in a way that
  implies sponsorship.
- Do not recolor, distort, rotate, outline, or add effects to an Espressif
  logo if written permission is obtained for a specific use.

Espressif's official logo guidance is the source for any future permitted logo
use: <https://www.espressif.com/en/about-espressif/logo-guidelines>.

## Product names

`EspBluFiNext` is the project and app name. Public descriptions should keep
the independent-project statement adjacent to the name. Prefer:

- `EspBluFiNext — independent BluFi diagnostics for ESP32 devices`
- `An iOS diagnostic client for Espressif BluFi-compatible ESP32 devices`

Avoid:

- `Espressif BluFi for iOS`
- `Official ESP BluFi Client`
- `Espressif BluFi Inspector`

If a future App Store listing uses “Espressif” in the product name or includes
an Espressif logo, obtain written permission and a trademark review first.
